# Roadmap

The ordered work list. No sprints and no phase gates — an item opens when the previous one runs, and every change passes `./check`. A row's status flips to done, with the date, only when its proof command passes; the position inside the active item lives in `CLAUDE.local.md`. Each item is an outcome a user can observe, proven by a deterministic test plus a live check. No item's deliverable is a document.
